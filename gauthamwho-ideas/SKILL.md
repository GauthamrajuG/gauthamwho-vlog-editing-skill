# GauthamWho ideas

Run only the **creative engine** of the `gauthamwho-edit` skill on: $ARGUMENTS

1. Read `~/.claude/skills/gauthamwho-edit/SKILL.md` (the "Story graphics (Job B)" part: "Ideas
   first", "Use the best skills at every stage" and "The realism checklist"),
   `reference/creative-engine.md`, the "Ideas" row of `reference/skill-routing.md`, and
   `D:/Claude/Video/lore.md`.
2. Check free memory as in `reference/pipeline.md` §0. Then analyse the clip as in Job A step 2:
   probe, shots, Tamil word timings and an English translation, and a contact sheet. If the
   creator has already edited and approved this reel, use the latest file in `Final video/`.
3. Build the opportunity inventory, write at least one idea per lens (10 or more raw ideas), and
   run the anti-generic filter.
4. Sketch the top 3: each is a rough panel drawn on the real frame at its moment, showing what
   appears, where it is and where it moves. Use the creator's body sides and give the screen
   side too. Put them on one sheet and send it.
5. Send one message (creative-engine §7): the inventory in 5–8 lines with times, the top 3 (time,
   what happens, why people will remember or send it, the lens, the effort, a one-line risk),
   the other ideas in one line each, and "Which one(s)? Or mix them."

Do **not** edit, cut or build anything. When they choose, continue with the gauthamwho-edit
Job B approval ladder: beat sheet → storyboard with the real 3D → still → preview with sound →
full video, with a yes at every step.
